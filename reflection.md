# AI Use Reflection

Claude Code est intervenu uniquement sur des tâches techniques — Git, structuration Markdown du dépôt — jamais pour construire l'argumentation. La recherche et l'identification des sources primaires (DEWR, JSA, ILO, OECD, Powering Skills Organisation) ont été menées par moi seul, ce qui m'a permis de repérer les écarts entre les sorties IA et le contenu réel des sources.

Deux exemples concrets. D'abord, le document de travail initial présentait une coupe budgétaire de 266,2 millions de dollars sur les incitations aux employeurs (Apprenticeships Priority List) comme un investissement ; j'ai détecté et corrigé cette inversion en revérifiant le Budget Paper No. 3 à la source. Ensuite, pendant la rédaction, j'ai demandé à Claude Code de simplement raccourcir une section — instruction de forme. Le résultat a modifié le fond : un chiffre sans provenance a été ajouté et la recommandation sur l'Option 3 a été inversée. J'ai comparé ligne à ligne avec ma version antérieure et refusé de committer ce résultat.

Ces deux cas révèlent des risques distincts : l'un factuel (une source mal restituée, détectable seulement par vérification directe), l'autre agentique (une instruction formelle dérivant en révision de fond, sans signal d'alerte apparent). C'est pourquoi je n'ai jamais validé une sortie IA sans relecture comparative systématique.
